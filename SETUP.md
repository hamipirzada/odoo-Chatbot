# 🤖 Odoo AI Analytics Chatbot - Setup Guide

## 📋 Quick Setup

### 1. Installation
```bash
# Copy to your Odoo addons directory
cp -r ai_analytics /path/to/odoo/addons/

# Install in Odoo
# Go to Apps → Update Apps List → Install "AI Analytics"
```

### 2. API Key Configuration
```bash
# Option 1: Use setup script
python3 setup_api_key.py

# Option 2: Manual setup in Odoo
# Settings → System Parameters
# Key: ai_analytics.groq_api_key
# Value: your_groq_api_key
```

### 3. Get Groq API Key
Visit: https://console.groq.com/keys (Free tier available)
